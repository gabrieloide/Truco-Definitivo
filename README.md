# 🃏 Truco Definitivo (Venezuelan Truco)

A robust multiplayer implementation of the traditional Venezuelan card game **Truco**, built from scratch in Unity. This project focuses on a decoupled, state-driven backend architecture capable of handling turn-based synchronization, state validation, and dynamic card interaction systems.

## 🛠 Features & Technical Highlights

*   **Turn-Based Sychronization:** Custom state-driven game loop that guarantees authoritative rule enforcement and synchronized player actions.
*   **Decoupled Architecture:** Solid core programming patterns separating visual gameplay execution from back-end state calculations to maintain clean, scalable code.
*   **Venezuelan Truco Ruleset:** Fully programmed logic accounting for standard mechanics (Envido, Flor, Truco calls, Vira card, and dynamic hierarchy scaling).
*   **Optimized Performance:** Built with mobile and light-web environments in mind, ensuring low memory allocation and efficient rendering loops.
